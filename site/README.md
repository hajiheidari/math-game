# Adadi website (adadi.espadna.com + espadna.com/adadi-app/)

| Address | What | Source |
|---|---|---|
| https://adadi.espadna.com | web game (no ads, no purchases), `?lang=en\|fa\|ar\|ur` | Flutter web (`app/`) |
| https://adadi.espadna.com/privacy/ | privacy policy, English + Persian (`#fa`) | `docs/privacy/index.html` |
| https://espadna.com/adadi-app/ (`fa/`, `ar/`) | landing pages | `site/adadi-app/`, generated by `site/landing_pages.py` |

Hosting: one Cloudflare Worker, `adadi` (`site/wrangler.jsonc`), deployed by `.github/workflows/site.yml`
on every push to `master` (secrets `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`, same values as
espadna-site). The config sets both addresses: `adadi.espadna.com` as a custom domain and
`espadna.com/adadi-app*` as a route on the espadna.com zone (a route wins over the espadna-site Worker,
which only shows Adadi's card). Same layout as Tiaro (`crowns-app`).

Build locally: `bash site/build.sh` (needs Flutter) → `dist-site/`.

Iran mirror: espadna.ir copies **adadi.espadna.ir** (game) and **espadna.ir/adadi-app** (landing) with
`mirror-ir/sync.php` in espadna-site, from the `files.json` that `site/manifest.py` writes at the root and
in `adadi-app/`. CanvasKit is bundled (no Google CDN), so the mirrored game works on the national internet.

Change the landing text or screenshots: edit `site/landing_pages.py` (or the `*.webp`), run
`python3 site/landing_pages.py`, commit. CI fails if the generated pages are out of date.
